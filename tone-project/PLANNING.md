# 서비스 기획서 — TONE (성향 컬러 테스트)

## 1. 서비스 개요

| 항목 | 내용 |
|---|---|
| 서비스명 | TONE |
| 한 줄 소개 | 몇 가지 질문으로 나만의 성향 컬러 카드를 뽑아보는 AI 성향 테스트 |
| 타겟 사용자 | 재미로 자기 이해를 하고 싶은 10~30대, 결과를 SNS/카톡으로 공유하고 싶은 사람 |
| 목표 | (1) 짧은 시간에 가볍게 즐길 수 있는 진단 경험 제공, (2) AI가 생성하는 '나만의 문장'으로 개인화 경험 제공, (3) 결과 카드 공유를 통한 자연스러운 확산 |

## 2. 페이지 / 섹션 구성

서비스는 SPA(단일 페이지) 구조로, 아래 4개의 화면(뷰)을 자바스크립트로 전환하며 상단 내비게이션(로고 클릭 시 홈 이동)으로 이동할 수 있습니다.

1. **홈 화면**
   - 히어로 영역: 서비스 소개, 테스트 시작 버튼
   - 스크롤 시 8가지 성향 유형 갤러리 노출 (스크롤 리빌 애니메이션)
2. **모드 선택 화면**
   - 빠른 진단(5문항) / 정밀 진단(10문항) 중 선택
3. **문제 풀이 화면**
   - 한 화면에 한 문제씩 노출, 진행률 바 표시
   - 이전/다음 이동, 미선택 시 안내 메시지 노출
4. **결과 화면**
   - 카드 플립 애니메이션으로 결과 공개
   - AI가 생성한 개인화 코멘트 + 정적 유형 설명 + 강점 태그 + 궁합 유형
   - 다시 하기 / 홈으로 / 카드 다운로드 버튼

## 3. 핵심 기능

### 3-1. 성향 진단 로직
- 3개 축(에너지 방향 E/I, 판단 방식 L/F, 실행 방식 P/S)의 조합으로 8가지 유형 결정 (2×2×2 = 8)
- 질문은 그때그때 생성하지 않고, 미리 정의된 10개 문항 세트를 사용
  - 빠른 진단: 10문항 중 대표 5문항 사용
  - 정밀 진단: 10문항 전체 사용
- 축별 응답 개수를 집계해 다수결로 유형 결정 (동점 시 특정 값으로 결정론적 처리)

### 3-2. AI 기능 (Gemini API)
- **입력**: 확정된 성향 유형(이름/코드/설명) + 사용자가 각 문항에서 선택한 답변 목록
- **출력**: 이 사람만을 위한 2~3문장의 개인화된 코멘트(친근한 말투, 마지막 문장은 오늘을 위한 응원/조언)
- **사용자에게 제공하는 가치**: 정해진 유형 설명에 더해, 자신의 실제 답변을 반영한 '나만을 위한 한마디'를 받아보는 개인화 경험
- **실패 처리 기준**
  1. 빈 입력 방지: 질문 미응답 시 다음 단계로 진행 불가 + "옵션을 선택해주세요" 안내
  2. API 오류(4xx/5xx): 토스트로 "AI 코멘트를 불러오지 못해 기본 카드로 보여드려요" 안내 후, 사전 정의된 유형 설명으로 자연스럽게 대체
  3. 지연/타임아웃(15초 초과): 요청을 중단하고 동일하게 기본 설명으로 대체하여 결과 화면 자체는 항상 정상 노출

## 4. 성향 유형 8종 요약

| 코드 | 이름 | 한 줄 설명 |
|---|---|---|
| ELP | 설계자형 | 논리와 계획으로 세상을 설계하는 사람 |
| ELS | 도전가형 | 빠른 판단과 배짱으로 정면 돌파하는 사람 |
| EFP | 리더형 | 사람들과 함께 목표를 향해 이끄는 사람 |
| EFS | 탐험가형 | 호기심을 따라 즉흥적으로 세상을 누비는 사람 |
| ILP | 분석가형 | 차분하게 파고들어 본질을 찾아내는 사람 |
| ILS | 몽상가형 | 혼자만의 상상 속에서 새로운 아이디어를 그리는 사람 |
| IFP | 중재자형 | 조용히 갈등을 다독이고 조화를 만드는 사람 |
| IFS | 조력자형 | 따뜻한 마음으로 곁을 지켜주는 사람 |

## 5. 반응형 / UX 고려사항

- 데스크톱(4열 카드 그리드) → 태블릿(2열) → 모바일(1~2열)로 그리드 자동 조정
- 모바일에서는 결과 화면 버튼이 세로 스택으로 전환, 터치 영역 확대
- 진행률 바 + "N / 총문항" 표시로 남은 분량 인지 가능하게 하여 이탈 방지
- `prefers-reduced-motion` 사용자를 위해 배경 블롭 애니메이션 비활성화 처리

## 6. 보너스 아이디어 (적용됨)

- 결과 카드 이미지 다운로드 기능(html2canvas) → SNS 공유 유도
- 스크롤 리빌 마이크로 인터랙션(유형 갤러리 카드 등장 애니메이션)
- 카드 플립 연출로 결과 공개 시 재미 요소 추가
